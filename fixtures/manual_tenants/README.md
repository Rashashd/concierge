# Manual Tenant Fixtures

These markdown files are sample tenant documents for local ingestion and manual multi-tenancy checks.

Tenant A, `tenant_a_policies`, contains policy-heavy service business documents about refunds, cancellations, support, privacy, and data handling.

Tenant B, `tenant_b_different`, contains unrelated coffee roastery documents about menu items, coffee classes, subscriptions, pickup, and location details.

Use these fixtures to ingest two tenants with clearly different knowledge bases, then ask tenant-specific questions against each tenant to confirm retrieval stays isolated.
