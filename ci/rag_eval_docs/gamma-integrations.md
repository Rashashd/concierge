# Gamma Software CRM Integrations

Sales operations teams usually ask whether the platform ships with direct CRM sync or whether they need to build webhooks and custom jobs first. The answer depends on the target system and the subscription tier.

Gamma Software includes native CRM integrations for HubSpot, Salesforce, and Pipedrive. Custom webhooks remain available on growth plans for workflows that are outside the native connector set.

Field mapping, sync cadence, and ownership rules are configured after the connector is authorized by an admin. Some customers still export data manually during procurement before the native sync is activated.

The product team publishes connector release notes separately from the core application changelog so admins can track CRM-specific updates.
