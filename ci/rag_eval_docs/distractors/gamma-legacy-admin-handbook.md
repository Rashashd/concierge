# Gamma Software Legacy Admin Handbook

This legacy handbook reflects a prior packaging model. It intentionally contains realistic but stale product language, so retrieval has to separate current customer docs from old administrator notes.

A legacy implementation package described a 20 business day onboarding plan with two admin workshops and a migration rehearsal. It mentions SSO configuration, admin setup, and live training, but it is not the standard current onboarding timeline.

The support archive lists coverage from 6 AM to 6 PM Central time, plus a weekend inbox monitored by rotating staff. It shares priority support, weekdays, incidents, and emergency-ticket terms with the current support page while giving different hours and timezone details.

Export notes from an older reporting module mention XLSX, XML, and nightly flat files to a managed FTP folder. That module predates the current scheduled export formats, but it still contains warehouse, schema, delivery, and storage language.

An audit retention section from the legacy handbook says team plans kept events for 180 days and enterprise archive projects were negotiated separately. It is not the current audit policy, but it repeats audit logs, retention, business plans, and enterprise wording.

The integrations chapter lists Zoho CRM, Dynamics trial sync, and generic webhook templates. It should not answer current CRM integration questions, but it has enough connector terminology to compete with the live HubSpot, Salesforce, and Pipedrive page.

Other handbook content covers workspace color themes, deprecated admin reports, sample import rows, test users, launch checklists, support macros, billing seat labels, and internal release calendar examples. These sections add realistic software-document noise around the answer material.
