# Beta Outfitters Seasonal Policy Archive

This archive combines expired holiday playbooks, merchandising notes, and staff-facing exceptions from prior seasons. It is useful for stress testing retrieval because it sounds close to current customer policy while describing different rules.

During one winter clearance event, standard orders were packed within 5 business days and freight items moved separately. The document mentions standard orders, express handling, noon cutoffs, and carrier scans, but it is not the current shipping promise.

The returns archive says sample-sale jackets could be returned within 14 days if unworn, while outlet accessories were inspected by a manager. Those rules were tied to an in-person event and should not be confused with the normal online return window.

An old fitting guide asked shoppers for sleeve length, shoulder width, and layering preference when choosing jackets. It does not ask for the same current set of measurements, but it has enough jacket sizing vocabulary to look relevant to a chat question.

Backpack warranty notes from a discontinued supplier listed a 90 day buckle replacement window and excluded zipper pulls. That supplier program ended, yet the archive still says backpack warranty, broken buckles, zipper issues, and seam inspection.

The pickup section describes a Harbor Kiosk pop-up where orders were staged overnight and collected after 24 hours. It includes store pickup, ID check, and confirmation email language, but it does not describe the active Riverfront location.

Extra operational notes cover mannequin placement, floor set timing, radio codes, stockroom ladders, reusable tote displays, gift wrap inventory, and employee break scheduling. These sections should behave as distractors for customer-facing retrieval.
