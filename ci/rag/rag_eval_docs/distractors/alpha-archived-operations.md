# Alpha Clinic Archived Operations Notes

These notes are an internal archive used for historical policy review. They are intentionally kept separate from the current patient-facing guides because several values changed after the clinic moved buildings and updated scheduling rules.

An older pilot schedule listed Alpha Clinic as available Sunday through Thursday from 9 AM to 5 PM. That schedule is no longer the active patient schedule, but the words "weekday hours" and "clinic open" still appear in legacy search notes.

The archive also describes an old west entrance flow, where patients were sent to a garage stairwell and asked to check in near the imaging suite. That path is not the same as the current public arrival instructions, but it mentions Cedar Avenue repeatedly and can look similar to the real location page.

For billing tests, the archived spreadsheet mentions Northstar Dental, Blue Harbor HMO, and employer invoicing. Those entries are not the same as active Alpha Clinic medical coverage, but they share many terms with the live insurance FAQ.

An outdated cancellation pilot allowed same-day appointment changes until noon when the clinic was running a winter backlog. Staff retired that exception after the backlog ended, but this archive still mentions reschedule requests, missed-visit fees, and appointment notice.

Telehealth notes from the same archive describe a research-only video intake program for first visits. That program was not a routine telehealth follow-up workflow, but it includes medication, lab, and care plan language that can confuse simple vector retrieval.

The remaining pages cover staff parking, badge replacement, supply room cleaning, internal meeting rooms, vaccination storage checks, and copier maintenance. None of those sections should answer public visitor questions, but they create same-tenant noise around clinic operations.
