# Gamma Software Onboarding Overview

Implementation calls usually start with workspace scoping, identity review, and a checklist of admins who will approve access settings. Most teams also ask when training happens relative to the first import.

Gamma Software onboarding for standard teams takes 10 business days and includes admin setup, SSO configuration, and one live training session. Larger enterprise launches can extend beyond that baseline when custom security review is added.

Sandbox workspaces are often prepared first so an operations lead can validate the structure before production data is imported. The implementation manager also confirms escalation contacts during kickoff.

Teams that postpone identity setup usually become the biggest source of onboarding delay, even when the rest of the checklist is already complete.
